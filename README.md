# Car Marketplace API

This is my Java project for managing car listings. I built it to practise Spring Boot and learn how to create REST APIs.

## Technologies

- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven
- Docker

## Features

- Add new cars
- Get a list of cars
- Find a car by ID
- Update car information
- Delete cars
- Search cars using filters
- Validate car data

## How to run

You need Java 21 and Maven to run the project.

1. Clone the repository.
2. Configure the database connection.
3. Run the application.

The API runs on `http://localhost:8080`.

## API documentation

If Swagger is configured, you can view the API documentation at:

`http://localhost:8080/swagger-ui/index.html`

## What I learned

While working on this project, I practised building REST APIs, working with databases, and organizing code into controllers, services, and repositories.
